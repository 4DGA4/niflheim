Excited to announce NIFLHEIM - An Educational Data Poisoning Toolkit for ML Security

I'm proud to share a project that's been in development: NIFLHEIM, an educational toolkit designed to help security professionals understand data poisoning attacks and defenses.

🔐 Why This Matters:

Machine learning systems are increasingly deployed in critical applications - from fraud detection to threat analysis. Yet many security teams lack hands-on experience with adversarial attacks.

NIFLHEIM addresses this gap through controlled, educational demonstrations.

🛡️ Key Features:

• Backdoor Attack Demonstrations - Learn how hidden triggers are embedded in ML models (with comprehensive safety controls)

• Model Collapse Simulator - Understand how poisoned training data degrades model performance over time

• Defensive Security Focus - Detection tools, mitigation strategies, and best practices for secure ML pipelines

📚 Expert Validation:

This toolkit is inspired by Addie LaMarr's excellent research presented in "Data Poisoning: The Fatal Flaw in Mass Surveillance" (785K+ views), and references academic literature from leading researchers in adversarial ML.

⚖️ Safety & Ethics:

NIFLHEIM is designed strictly for educational and defensive security use:
• Mandatory educational use flags on all operations
• Comprehensive audit logging
• Parameter limits and safety controls
• Synthetic datasets only
• AGPL-3.0 licensed

🎯 Use Cases:

• University courses on ML security
• Corporate security training programs
• Red team exercises (authorized)
• Privacy advocacy education
• Academic research

⚙️ Technical Details:

• Python 3.10+
• 196 passing tests (production-ready)
• Comprehensive documentation
• Safety controls validated
• Browser extension (Manifest V3)

🚀 Looking Ahead:

I'm particularly interested in connecting with:

• Contributors interested in advancing ML security education
